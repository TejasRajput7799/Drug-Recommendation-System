# Drug Recommendation System

## Project Overview
The Drug Recommendation System is a Django-based web application designed to provide medicine suggestions based on disease, symptoms, and user age.

## Objectives
- Provide symptom-based medicine recommendations.
- Consider age when matching medicines.
- Maintain disease and medicine information in a database.
- Provide a simple and user-friendly interface.

## Technologies Used
- **Backend:** Python, Django
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Development Environment:** PyCharm
- **Database Management:** XAMPP / phpMyAdmin

## Main Features
- User registration and login
- Disease and symptom matching
- Age-based medicine recommendations
- Admin management of disease and medicine information
- Contact and feedback forms

## Project Modules
1. User Module
2. Symptom Analysis Module
3. Medicine Recommendation Module
4. Admin Module
5. Feedback and Contact Module

## Installation
1. Install Python and Django.
2. Install and configure MySQL.
3. Open the project folder in a terminal.
4. Install the required dependencies using `pip install -r requirements.txt`.
5. Configure the database settings.
6. Run database migrations using `python manage.py migrate`.
7. Start the application using `python manage.py runserver`.
